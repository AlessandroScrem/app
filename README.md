# Simple Renderer Wgpu 

A modern 3D/2D render engine that uses wgpu

## Features

- [x] Ecs 
- [x] Phong shading
- [x] Imgui
- [x] Mesh entity
- [x] Light entity
- [x] SkyBox
- [x] IBL
- [x] PBR
- [ ] Docking Gui
- [ ] Hierarchy entity
- [ ] Mesh Bounding box
- [ ] Entity selection
- [ ] Outline on selection
- [ ] Direct Light shadow
- [ ] SSAO
