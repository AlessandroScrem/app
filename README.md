# Simple Renderer Wgpu 

A modern 3D/2D render engine that uses wgpu

## Features

- [x] Ecs 
- [x] Phong shading
- [x] Imgui
- [x] Mesh entity
- [x] Light entity
- [x] SkyBox
- [x] IBL
- [x] PBR
- [x] Exposure
- [x] Tonemapping
- [x] Skybox selctor
- [x] xyz Axis
- [x] Docking Gui
- [x] Mesh Bounding box
- [ ] Entity selection
- [ ] Outline selection
- [ ] Hierarchy entity
- [ ] Direct Light shadow
- [ ] SSAO   
- [ ] 

## Platforms
 - [x] Windows
 - [ ] Linux
 - [ ] MacOs

## Compiling and running

```bash
git clone https://github.com/AlessandroScrem/app.git
cd app

# At the reposity root
cargo build

cargo test

cargo run 
```
